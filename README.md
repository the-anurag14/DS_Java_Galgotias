# 🔗 Data Structures in Java - Galgotias

Custom Data Structures implementations in **Java**, maintained by **Anurag Kumar** (Galgotias University).

---

## 📌 Contents

- **`LinkedListDemo.java`**: Custom Singly Linked List implementation featuring:
  - `add(int data)`: Insert elements at the end
  - `display()`: Traverse and print elements
  - `reverse()`: In-place iterative linked list reversal ($O(N)$ time, $O(1)$ space)

---

## 🚀 How to Run

Compile and execute using standard Java CLI:

```bash
javac LinkedListDemo.java
java LinkedListDemo
```

### Expected Output:
```
1->2->3->2->4->5->
5->4->2->3->2->1->
```
